# SyntaxWear

SyntaxWear é um projeto de e-commerce de tênis e sneakers, desenvolvido como parte do curso DevQuest 2.0. O objetivo do projeto é criar uma interface de loja virtual moderna e atraente, utilizando as tecnologias web fundamentais: HTML e CSS.

## 🚀 Funcionalidades

- **Página Inicial:** Apresenta os produtos em destaque, categorias e promoções.
- **Navegação:** Menus de navegação para categorias de produtos (Masculino, Feminino, Outlet), páginas institucionais (Nossas lojas, Sobre) e acesso do usuário (Minha conta, Ajuda, Carrinho).
- **Design Responsivo:** O layout se adapta a diferentes tamanhos de tela, proporcionando uma boa experiência tanto em desktops quanto em dispositivos móveis.
- **Componentes de UI:**
  - Header com logo e menus de navegação.
  - Seção "Hero" com imagem de destaque e chamadas para ação.
  - Grid de categorias de produtos.
  - Grid de produtos em destaque.
  - Footer com links de navegação, formulário de newsletter e redes sociais.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Para a estruturação semântica do conteúdo.
- **CSS3:** Para a estilização e o layout dos componentes.

## 📂 Estrutura de Arquivos

O projeto está organizado da seguinte forma:

```
ecommerce-syntaxwear/
├── css/
│   ├── base.css
│   ├── reset.css
│   ├── variables.css
│   └── components/
│       ├── footer.css
│       ├── header.css
│       ├── hero.css
│       ├── product-category.css
│       └── product-grid.css
├── images/
│   ├── banners/
│   ├── favicons/
│   ├── icons/
│   ├── logo/
│   └── products/
├── js/
├── index.html
└── README.md
```

- **css/:** Contém os arquivos de estilização.
  - `base.css`: Estilos base para o corpo da página, como fontes e cores.
  - `reset.css`: Reseta os estilos padrão dos navegadores.
  - `variables.css`: Define as variáveis de cores e outras propriedades CSS.
  - `components/`: Contém os estilos para cada componente da interface (header, footer, etc.).
- **images/:** Armazena todas as imagens utilizadas no projeto, organizadas por tipo.
- **js/:** Pasta reservada para futuros arquivos JavaScript.
- **index.html:** A página principal do e-commerce.
- **README.md:** Este arquivo.

## 📖 Como Utilizar

Para visualizar o projeto, basta abrir o arquivo `index.html` em seu navegador de preferência.

```bash
# Clone o repositório (opcional)
git clone https://github.com/seu-usuario/ecommerce-syntaxwear.git

# Acesse o diretório do projeto
cd ecommerce-syntaxwear

# Abra o arquivo index.html no navegador
```
